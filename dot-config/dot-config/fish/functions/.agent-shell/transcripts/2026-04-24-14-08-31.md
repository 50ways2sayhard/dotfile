优化完成。对比原版的关键变化：

**【品味评分】** 🟢 好品味

**【核心改动】**
1. **数据源修正** — 从 `PWD` / `$argv[1]` + `realpath` 改为 `git rev-parse --show-toplevel`。消除了"传入子目录时 magit 打开的是子目录而不是仓库根"这个特殊情况。真正的数据是 git 根，不是用户当前在哪。
2. **错误边界** — 不在 git 仓库时直接返回非 0，而不是把一个废路径塞给 magit。
3. **窗口聚焦方式** — 用 `osascript` 在 macOS 层把 Emacs 进程提到前台。原来的 `select-frame-set-input-focus` 只切 frame 焦点，不把 Emacs.app 从后台拎到前台。加 `uname = Darwin` 守卫，非 macOS 环境安全跳过。
4. **参数透传** — 对齐参考脚本的 `"$@"`，支持 `magit file.txt` 之类的用法（如从 IntelliJ 启动）。
5. **去掉 `-n`** — `emacsclient -e` 评估 lisp 后立即返回，`-n` 对 `-e` 是冗余的。

**【保留决定】**
- 没硬编码 `/opt/homebrew/bin/emacsclient`，走 PATH 更便携。fish 的 `command -v` 兜底交给调用者环境处理。
- 没加 `set -o errexit` 等价物——fish 里每个关键点已经显式检查，没必要全局 abort。
