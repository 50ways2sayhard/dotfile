修改完成。变更说明：

**问题**：原函数用 `git rev-parse --show-toplevel` 在 **当前 shell 的 PWD** 找 git root，忽略了传入的路径参数。

**修复**：
1. 接受第一个参数作为目标路径（无参数时回退到 `$PWD`）
2. 校验路径存在；若是文件则取其所在目录
3. 用 `git -C "$target_path" rev-parse --show-toplevel` 从目标路径解析 git root

这样 `magit /some/repo/subdir/file.ts` 就会正确定位到 `/some/repo` 并打开 magit-status。
